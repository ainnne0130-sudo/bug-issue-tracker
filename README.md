# Bug / Issue Tracker

A simple and responsive web-based Bug / Issue Tracker that allows users to create, manage, filter, and track issues.

## Features

- Create new issues
- Add issue title and description
- Set issue priority
- Set issue status
- View issue list
- Display issue date
- Change issue status
- Delete issues
- Filter issues by status
- Search issues
- Open / In Progress / Closed dashboard
- Data saved using localStorage
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome

## Issue Status

- Open
- In Progress
- Closed

## Priority Levels

- Low
- Medium
- High
